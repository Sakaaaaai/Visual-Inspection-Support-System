# 動物画像 目視確認アシスト

解析結果のExcelを読み込み、対応する画像をブラウザへ1枚ずつ表示して、目視結果をExcelへ保存するローカルアプリです。Windows / macOS / Linuxで動作します。

## 起動方法

依存関係の管理には [uv](https://docs.astral.sh/uv/) を使用します。事前にインストールしてください。

### Windows

1. `start.bat` をダブルクリックします。
2. 初回だけ必要なライブラリが自動インストールされます。
3. ブラウザが開いたら、解析結果フォルダを選択します。

アプリを終了するときは、起動時に表示された黒い画面を閉じます。

### macOS / Linux

1. 初回のみ、ターミナルで以下を実行して環境を構築します。
   ```sh
   ./setup.sh
   ```
2. アプリを起動します。
   ```sh
   ./start.sh
   ```
3. ブラウザが開いたら、解析結果フォルダを選択します。

アプリを終了するときは、ターミナルで `Ctrl+C` を押します。

## 対象となる構成

```text
003001_260721/
├─ result_003001_260721_all.xlsx
├─ device/
│  └─ 003001_260721_inf_serow/
│     └─ 画像.jpg
└─ server/
   └─ 003001_260721_inf_serow/
      └─ 画像.jpg
```

画像は、Excelの装置番号・解析日・デバイス・動物名・ファイル名から自動的に特定します。最初に `inf` フォルダを確認し、Excelが `.jpeg`、画像が `.jpg` のように拡張子だけ異なる場合も同じ画像として扱います。`inf` に画像がなければ、同じ動物名の `org` フォルダを確認します。

## 保存規則

- 変更するセルは「目視による動物名」と「目視による数」だけです。
- 予測動物名と目視結果が同じ場合、「目視による動物名」は空欄になります。
- `いない`を選んだ場合、「目視による動物名」は `いない`、「目視による数」は空欄になります。
- それ以外では「目視による数」に0以上の整数が必要です。
- 最初の保存時に、対象Excelと同じフォルダへ日時付きバックアップを作成します。
- Excelを開いたままだとWindowsが保存を拒否するため、対象Excelを閉じてから作業してください。誤って開いた場合はExcelを閉じ、入力画面に戻ってもう一度「保存して次へ」を押してください。

## 画面モードと主な操作

画面右上のタブで、以下の2つのモードを切り替えて作業できます。

### 1枚ずつ確認
AIの解析結果と対象画像を1枚ずつ見ながら確認する基本モードです。
- `Enter`: 保存して次へ
- `Ctrl+S`: 現在の入力を保存
- `←` / `→`: 前後の画像へ移動（入力変更があれば先に保存）
- **次の未入力へ**: 未確認の画像へ移動
- **時間が近い写真**: 画像の左側に、現在の写真の直前・直後を各2枚まで参考表示します。Excelに載らなかった未検出画像も `server` / `device` 直下から探して表示します（判定対象は変わりません）。
- **拡大画面**: 「画像を拡大」から、`＋` / `−`やマウスホイールで最大600%まで拡大できます。拡大後はドラッグして表示位置を移動します。

### 動物別一覧
AIが判定した動物ごとに画像を一覧表示し、一括で確認・修正するモードです。サイドバーから「すべて」を選ぶと全画像を横断して確認できます。
- **レイアウト変更**: 画面左上の「縦」「横」から、画像の表示枚数（グリッドサイズ）を自由に変更できます（「全て選択」の横に横並びで配置されています）。
- **一括選択**: マウスでドラッグして複数の画像をまとめて選択できます。すでに選択された画像を再度ドラッグすると選択解除になります。
- **全解除**: `Escape` キーを押すと、すべての選択をすばやく解除できます。
- **詳細確認**: 画像をダブルクリックすると「1枚ずつ確認」モードへ移動して拡大などの詳細確認ができます。移動後は「← 一覧に戻る」ボタンで元の状態へ戻れます。
- **一括保存**: 画面右側のパネルから、選択した複数の画像に対して「動物名」と「数」を一括で上書き保存できます（「いない」などの修正に便利です）。「(AI予測のまま)」を選択して保存した場合は、AIの予測結果を正しいものとして一括保存します。また、**「チェック済みを保留にする」**ボタンで選択画像を保留状態（オレンジ枠で表示）にできます。

### 1枚ずつ確認（補足）
- **保留にして次へ**: 専用の保留ボタンを押すと、その画像を保留状態（オレンジ色のバッジで表示）にして次の画像へ進みます。
- **次の保留へ**: 「次の未入力へ」ボタンのすぐ下に配置されており、保留状態の画像へ直接ジャンプできます。

## 注意

このアプリは各PCの `127.0.0.1` だけで動作し、外部へ公開しません。画像認識は行わず、人による確認作業を支援します。
